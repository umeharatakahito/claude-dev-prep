# Claude Certified Developer – Foundations 対策サイト

実力診断（36問）→ 分野別の弱点 → 優先順位と日程の計画、を出す静的サイトです。
ビルド不要。`index.html` を開くか、`python3 -m http.server` で配信します。GitHub Pages にもそのまま置けます。

- 問題は自作の練習問題です（公式問題ではありません）。ブループリントは試験ガイド v1.0（2026年7月発効）に基づきます。
- 試験内容は 2026年12月7日に更新されます。更新版ガイド（11月17日公開予定）が出たら `questions.js` の `DOMAINS` を見直してください。
- 結果はブラウザの localStorage にだけ保存されます。
